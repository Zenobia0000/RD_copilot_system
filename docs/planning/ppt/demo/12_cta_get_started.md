## 重點內容

### 三步驟試用

1. **提供一個 RD 問題** — 卡關的設計、複雜的 trade-off、新專案概念都可以
2. **30 分鐘 onboarding** — 環境設定 + 你的需求對焦 + 系統能力 walkthrough
3. **第一週產出概念凍結** — 跑完 TRIZ Step 0-5，拿到 WI/MC/ICD 工程交付物

### 試點門檻刻意低

- 不需要懂 TRIZ — 系統會引導
- 不需要新基礎設施 — 跑在現有開發環境
- 不需要全公司導入 — 一個人、一個議題就能跑

### 為什麼是現在試用

- PoC 已驗證（eBike session 完整跑通，22 份交付物）
- Phase II 收斂中 — 早期試用者意見會直接影響產品定型
- 第一批試用者享有 1-on-1 陪跑（後續會自助化）
