## §4 風險回應策略 (Top 5)

### 1. TR-01 AI 幻覺 (P×I = 20) — **Mitigate**

- **短期**: 所有 AI 輸出強制附帶 Confidence Score + 來源引用。
- **中期**: RAG retrieval 品質監控 dashboard + 自動 flag 低信心輸出。
- **長期**: 建立 Hallucination Detection Agent 作為 Multi-Agent 架構的一部分。

### 2. TR-02 輸入負擔 (P×I = 16) — **Mitigate**

- **短期**: AI 預填所有可推斷欄位，用戶只需確認/修改。
- **中期**: 自然語言輸入 → AI 結構化轉換 (降低學習曲線)。
- **長期**: 與 CAD/PLM 整合，自動匯入設計參數。

### 3. BR-01 市場採納 (P×I = 16) — **Mitigate**

- **短期**: 免費 Pilot Program + 選定 2-3 家 Design Partner。
- **中期**: Champion Program — 培養企業內部推廣者。
- **長期**: 建立用戶社群 + 案例分享。

### 4. BR-02 法規 / IP 風險 (P×I = 15) — **Mitigate**

- **立即**: 啟動 PDPA 合規評估 (見 E1x--privacy-compliance-seed.md)。
- **短期**: 租戶隔離架構設計 + 資料加密方案。
- **中期**: SOC 2 Type I 認證準備。

### 5. BR-03 資金跑道 (P×I = 15) — **Accept + Monitor**

- **立即**: 明確 PMF milestone 與 burn rate 上限。
- **短期**: 設定融資觸發條件 (runway < 9 months)。
- **中期**: 達成 PMF 後啟動 Series A。
