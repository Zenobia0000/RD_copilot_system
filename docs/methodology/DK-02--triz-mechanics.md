## §2 TC：39 參數 + 矩陣 + 40 原理

### §2.1 KB 操作協議

**輸入**：Step 1 的「改善什麼」與「惡化什麼」自然語言描述。

**步驟**：

1. **參數映射** (`01_39_parameters.md`)
   - 「改善什麼」→ 39 參數之一（用 KB 末尾 LLM 映射提示）
   - 「惡化什麼」→ 39 參數之一
   - 不直接對應 → 找最近參數 + 記錄映射理由
   - 產出：`(P_improve, P_worsen)` 參數對

2. **矩陣查表** (`02_contradiction_matrix.md`)
   - 用 (P_improve, P_worsen) 查行 → 候選原理編號（通常 2-4 個）
   - 格值為空 → 此組合無經典推薦，直接走 §4 分離路徑
   - 注入：僅檢索相關行（~200 token/行）

3. **原理具體化** (`03_40_principles.md`)
   - 對每個候選原理，閱讀物理本質與跨域範例
   - 回答**具體化三問**：

| 問題 | 目的 |
|:-----|:-----|
| a. 控制方程在我的 OZ 內適用嗎？ | 確認物理可實現 |
| b. 跨域範例中哪個物理機制最接近？ | 找跨域類比錨點 |
| c. 翻譯為我的系統的 F 和 S 是什麼？ | 從類比到具體 |

**產出**：每 TC 的 2-4 個候選方向（含初步 F/S）。

### §2.2 候選方向品質門檻

> 候選中至少有一個能寫出**控制方程**。全部停留在類比層級（「像 XX 一樣」）= 具體化不足，需回 KB 查更多跨域範例。

### §2.3 數據驗證（v2 強化）

候選方向中的數值聲明須經外部數據驗證：
- 用 WebSearch 查詢
- 記錄到 Evidence Registry
- 標記 VERIFIED / APPROXIMATE / UNVERIFIED
- 禁止無 Claim ID 標註的數值出現在產出

## §3 PC：OZ-OT-Px 提取

### §3.1 轉換公式

```
TC: 改善 P1 → 惡化 P2
     ▼ 追問：P1 與 P2 共同受什麼控制？
     ▼
找到中介物理變數 Px
     ▼
PC: Px 必須是 [A]（為了 P1）且 Px 必須是 [¬A]（為了 P2）
```

### §3.2 OZ-OT 鎖定

| 步驟 | 問題 | 目的 |
|:-----|:-----|:-----|
| OZ | 衝突發生在哪個位置？ | 從整個系統縮到衝突點 |
| OT | 衝突發生在什麼時間？ | 找參數在不同時間的不同需求 |
| Px | 在 OZ × OT 內，哪個物理特性是兩難根源？ | 鎖定 PC 核心參數 |

### §3.3 Px 搜索流程

1. **列舉**：在 OZ 內列出所有可量化物理量（長度、溫度、力、電壓、流速、密度...）
2. **逐一追問**：對每個 Xi 問「單獨改變 Xi，P1 / P2 分別怎樣？」
3. **篩選候選**：Xi↑ 致 P1↑ 且 P2↓（或反向）→ Xi 是 Px 候選
4. **多候選排序**：選對 P1 / P2 靈敏度都高的（∂P1/∂Xi 與 ∂P2/∂Xi 都大）
5. **分離驗證**：對首選 Px 嘗試 4 種分離原理。全部不可行 → 回候選清單選次選
6. **候選耗盡** → §3.5 三種找不到情境
7. **三種情境也無解** → DK-01 §9 喊停

### §3.4 量化靈敏度評分（v2）

Px 選擇用評分矩陣：

| Px 候選 | ∂P1/∂Xi | ∂P2/∂Xi | 可量測？ | 可控制？ | 總分 |
|:--------|:--------|:--------|:--------|:--------|:-----|
| Px₁ | ... | ... | ... | ... | ... |

得分最高者進 §3.6 PC 造句驗證。

### §3.5 Px 找不到的三種情境

Px「一定存在」是假設，不是定律。以下情境 Px 可能不存在：

| 情境 | 表現 | 處理 |
|:-----|:-----|:-----|
| **長鏈耦合** | P1 與 P2 之間隔了 3+ 中間變數 | 用因果鏈上「最敏感的中間節點」當 **Proxy-Px**。造句改用「改變 Proxy-Px → 觀察 P1/P2 是否朝相反方向」 |
| **多變數共控** | P1 受 Px₁ 控制、P2 受 Px₂ 控制（Px₁ ≠ Px₂） | 不是一個 PC，是兩個獨立 PC → 分別做分離，再用 SIM 評估交互（§7） |
| **非物理耦合** | P1 / P2 關聯是商業/法規約束 | TRIZ 不適用此矛盾 → 拆出去用其他工具 |

### §3.6 PC 造句驗證

```
若 [Px] 是 [A]，則 [優點 1] 成立，但 [缺點 2] 出現；
若 [Px] 是 [¬A]，則 [優點 2] 成立，但 [缺點 1] 出現。
```

填得出 = Px 邏輯自洽。**邏輯自洽 ≠ 物理正確**；最終實驗在 Step 4。

**Proxy-Px 造句**（長鏈耦合用）：

```
改變 Proxy-Px 的方向（↑ 或 ↓）：
觀察 P1 是否朝期望方向？P2 是否朝反方向？
兩者皆是 → Proxy-Px 有效
僅一者 → Proxy-Px 位置不對，沿因果鏈前/後移一節點重試
```

## §4 分離原理

### §4.1 4 大分離原則 + 觸發問題

| 分離類型 | 觸發問題 | 控制方程舉例 |
|:---------|:--------|:------------|
| **時間** | A 與 ¬A 在不同時間出現？ | 週期切換（佔空比）、相變觸發、預動作 |
| **空間** | A 與 ¬A 在不同位置需要？ | 屏蔽層、梯度材料、嵌套結構 |
| **條件** | A 與 ¬A 在不同條件下需要？ | SMA、磁流變液、相變材料、感測響應 |
| **系統層級** | 整體要 A，局部可以 ¬A？ | 微觀大 / 宏觀小（碎形、多孔、複合） |

### §4.2 第一性原理三問驗證

對每個候選分離策略：

| 問題 | 目的 |
|:-----|:-----|
| a. 控制方程是什麼？（哪條物理定律保證 A 和 ¬A 可被分離？） | 物理可行 |
| b. 邊界條件是什麼？（在什麼範圍此分離有效？） | 適用範圍 |
| c. 至少一個跨域實例證明此分離在物理上可行？ | 經驗驗證 |

優先選擇符合 DK-01 §9.4 演化方向的策略。

### §4.3 四維診斷矩陣（v2）

對 PC 同時診斷 4 個分離維度，可能多個適用 → 嵌套組合（如「空間 + 條件」雙重分離）。

## §5 SF：76 標準解 + 5 大類路由

### §5.1 SF 圖標準形式

```
S1（工具） ──F（場）──▶ S2（物件）
診斷狀態：無效 / 有害 / 不足 / 缺失 / 計量
```

### §5.2 SF 狀態 → 標準解大類路由

| SF 診斷 | 首選大類 | 說明 |
|:--------|:--------|:-----|
| **不完整**（缺 S1、S2 或 F） | Class 1.1（建構 Su-Field） | 補全缺失元素 |
| **有害作用**（三要素齊但有副作用） | Class 1.2（消除有害） | 引入 S₃ 或反向場 |
| **效能不足**（三要素齊但效果不夠） | Class 1.3（強化）/ Class 2（場演化） | 強化現有或換場 |
| **需量測/偵測** | Class 4（偵測與量測） | 偵測標準解 |
| **物質受限**（空間/成本/相容性） | Class 5（物質導入變通） | 間接引入策略 |

### §5.3 分離策略 → SF 標準解銜接

分離策略告訴你「怎麼把 A 和 ¬A 分開」；SF 標準解告訴你「用什麼 F 和 S 實現」。

| 分離策略 | 典型 SF 操作 | 常用大類 |
|:---------|:------------|:--------|
| 時間分離 | 引入時間控制場（週期、預動作、相變） | Class 1.3 + Class 2.2 |
| 空間分離 | 引入空間隔離物質（屏蔽、梯度、嵌套） | Class 1.2 + Class 1.1 |
| 條件分離 | 引入條件響應材料/場（SMA、磁流變、相變） | Class 2.4 + Class 3 |
| 整體局部分離 | 改變微觀結構（碎形、多孔、複合） | Class 1.3 + Class 5 |

> 啟發性映射，不是剛性規則。實際操作時應在對應大類搜索 + 檢查相鄰類別。

### §5.4 SF-only 快車道

當 Step 1 SF 診斷狀態為「缺失」或「不足」、且**無副作用**：

```
Step 1 SF 確認 → §5.2 路由 → 不經分離原理，直接搜大類
                              → 科學效應導入 → 具體方案 → Step 4 驗證
```

跳過 Step 2/3。適用：功能補全、無 trade-off 的能力升級。

## §6 跨域去錨定（L1 內建）

### §6.1 三段式去錨

從 KB `03_40_principles.md` 的跨域範例出發：

```
1. 取出原理的物理本質（不是表面現象）
2. 找跨域範例（航太、生物、半導體...）中物理機制最接近的
3. 回到我的系統：F 是什麼？S 是什麼？OZ 是什麼？OT 是什麼？
```

### §6.2 反錨定檢查

> 候選方向不應只說「像 XX 一樣」。必須能回答：「我的系統中對應的 F = ____，S = ____」。

舊版 DK-02 的「Anti-Anchor Sprint」（v3.0 退役）已合併到此處 — 不再是獨立模組，而是 L1 原理具體化的內建步驟。

## §7 SIM 矩陣評分

### §7.1 適用時機

多 TC 之間獨立、無明顯主從關係，需同時評估解法間的相容性。詳見 DK-01 §5.4。

### §7.2 兩階段評分

**Step 2b 粗篩**（基於 OZ/OT）：

| 條件 | 標記 |
|:-----|:-----|
| 不同 OZ 或不同 OT | 中性 |
| 相同 OZ 且相同 OT | 潛在衝突 |

**Step 3b 精篩**（基於具體 F/S）：

| 分數 | 意義 | 判斷 |
|:----:|:-----|:-----|
| **+1** | 加成 | 解法 A 副產品是 B 的輸入，或共享物理機制 |
| **0** | 中性 | 不同 OZ 或 OT，物理上不干涉 |
| **-1** | 消弭 | 解法 A 的場/物質與 B 衝突 |

### §7.3 物理依據

| 條件 | 結果 |
|:-----|:-----|
| OZ/OT 不重疊 | 中性 (0) |
| OZ/OT 重疊 + Fx 與 Fy 相容 | 可能 +1 |
| OZ/OT 重疊 + Fx 與 Fy 相斥 | -1 |
| Sx = Sy（共用同物質） | 高機率 +1 |
| Sx 與 Sy 化學/物理不相容 | -1 |

### §7.4 -1 處理

-1 = 跨 TC 新矛盾：

```
解法 a（解 TC1）與解法 b（解 TC2）衝突
├─ OZ/OT 重疊 → 新 TC → 回 Step 3 深挖 → 精篩 SIM 重評
└─ OZ/OT 不重疊 → 接受為設計限制，記入規格書
```

### §7.5 收斂規則

| 規則 | 條件 | 動作 |
|:-----|:-----|:-----|
| 最大迭代 | 預設 N=2 輪 | 停止迭代，進終止判定 |
| 收斂度量 | 第 N+1 輪 -1 數量 ≥ 第 N 輪 | 立即停止，未收斂 |
| 終止 A | 殘餘 -1 OZ/OT 不重疊 | 接受為設計限制 → Step 4 |
| 終止 B | 殘餘 -1 OZ/OT 重疊 | 升級至 §9 喊停 |

> 預設 2 輪依據：第 1 輪 -1 產生的新 TC 通常是原 TC 的鄰域問題，第 2 輪即可判斷收斂。2 輪後仍未收斂 = 問題本質超出組合篩選範圍，需架構層級重思。
